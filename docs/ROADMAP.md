# Proposed 12-month roadmap

This is a future plan. It is not a statement that these milestones have already been completed.

| Period | Proposed milestone | Validation |
|---|---|---|
| Month 1 | Stabilize model integration and safe repository intake | Repeatable local smoke tests |
| Month 2 | Structured agent plan and traceable tool events | Saved trace for each tool call |
| Month 3 | Python and JavaScript syntax-aware analysis | Labeled sample repository suite |
| Month 4 | Safer patch validation and test selection | Patch regression tests |
| Month 5 | Git worktrees and review workflow | Original working tree remains unchanged |
| Month 6 | Bounded repair/retest loop | Fixed retry budget and deterministic stopping |
| Month 7 | Large-repository indexing | Context selection evaluation |
| Month 8 | Authentication and multi-user isolation | Security review and access-control tests |
| Month 9 | Reproducible benchmark suite | Human-reviewed issue labels |
| Month 10 | Model/cost/latency evaluation | Published methodology and measurements |
| Month 11 | Accessibility and deployment reliability | Automated UI and uptime checks |
| Month 12 | External security review and stable release | Findings triaged and release checklist met |
